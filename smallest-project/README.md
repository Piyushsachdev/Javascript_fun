


# Mouse Button Checker

This project detects which mouse button was clicked.

## What it does
- Left click shows a green message
- Middle click shows a blue message
- Right click shows a red message

## How to run
- Open the HTML file in a browser
- Click inside the box
- The text updates according to the mouse button pressed

## Files
- js2.html

## JavaScript concept used
- event.button
- document.getElementById()
- inline event handling
