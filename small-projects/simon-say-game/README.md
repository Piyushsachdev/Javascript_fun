
# Simon Say Game

A small JavaScript memory game inspired by Simon.

## Project idea
The game shows a random color pattern, and the player must repeat it in the same order.

## How to run
- Open the HTML file in a browser.
- Press any key to start the game.
- Follow the flashing pattern and repeat it.

## Files
- index.html
- style.css
- app.js

## Skills used
- JavaScript
- DOM manipulation
- event listeners
- arrays and logic
